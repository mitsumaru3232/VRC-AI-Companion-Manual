# 使うAIを選ぶ

VACには、**返事を作るAI**と、**声を文字にする音声認識**があります。
ここで設定するのは返事を作るAIです。音声認識の設定は[別のページ](../audio/models.md)で行います。

## どちらで使いますか？

| 方式 | 特徴 | 準備 |
| --- | --- | --- |
| パソコン内のAI | PCの処理能力を使う。ローカルモデルの実行にクラウドAPIの従量料金は不要 | [Ollama](ollama.md)と会話モデルを入れる |
| インターネット上のAI | 返答生成を外部サービスに任せる。会話のテキスト等が送信される | 提供元のアカウント・APIキー・必要な課金設定 |

クラウドAIは次の3サービスに対応しています。**1つ選べば始められます。すべての契約は不要です。**

| 使いたいサービス | VACの表示 | 準備するページ |
| --- | --- | --- |
| OpenAI | OpenAI（インターネット） | [OpenAIのAPIキー](openai.md) |
| Claude | Anthropic（インターネット） | [Anthropic・ClaudeのAPIキー](anthropic.md) |
| Gemini | Google Gemini（インターネット） | [Google GeminiのAPIキー](gemini.md) |

外部サービスの料金・無料枠・利用できるモデルは変わります。契約前に各公式ページを確認してください。

## 「AI を選ぶ」と「AI の設定」の違い

- **AI を選ぶ**：Ollamaで動かすローカルモデルを探してダウンロードするページ。
- **AI の設定**：実際に使う提供元とモデルを選ぶページ。クラウドのAPIキーもここで登録します。

**先に読む：[料金とAPIキーの注意点](costs-and-keys.md)**

**キーがある方：[アプリに登録する](register.md)**
