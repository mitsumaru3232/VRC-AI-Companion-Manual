# VRChatに返答を表示する

まずは **標準チャットボックス** を使いましょう。文字表示のために特別なアバターを用意する必要はありません。

## 1. VRChatのOSCをオンにする

VRChatを起動し、Action Menu（円形メニュー）の **OSC → Enabled** を有効にします。
メニューの位置が異なる場合は、[VRChat公式のOSC設定案内](https://docs.vrchat.com/docs/osc-overview#enabling-it)を確認してください。

## 2. VACからの出力を設定する

1. VACの **「VRChat 連携」** を開く。
2. **「VRChat に送る」** をオンにする。
3. 「表示する場所」を **「標準チャットボックス（基本）」** にする。
4. ページ下部の **「保存する」** を押す。

![VRChatへの出力設定。最初は標準チャットボックスを選びます。](../assets/screenshots/vrchat.png)

## 3. 実際の表示を確認する

「会話」で短い文章を送り、AIの返答がVRChat内にも表示されるか確認します。
ページ下部の送信テストも利用できます。

VACが送信できたことと、VRChat側に表示されたことは別です。必ずVRChat内でも見て確認してください。
他の人から見えない場合は、相手側のチャットボックス表示設定も確認します。

## 長い返答・入力中表示

長い返答は分割して表示します。
「考えている間『入力中…』を出す」で、返答生成中の表示を切り替えられます。
送信時の通知音も設定できます。

## KATの文字盤を使う場合

ムチォを使う方は、[ムチォの文字盤にAIの返答を表示する](mucho.md)に沿って設定してください。

KAT（KillFrenzy Avatar Text）は対応アバターの文字盤を使う拡張機能です。
アバター側への導入が必要で、VACの設定だけでは文字盤は追加されません。
導入は対応アバター・文字盤の説明書に従ってください。

「表示する場所」で文字盤のみ、または標準チャットボックスとの併用を選べます。
文字盤の表示時間や、漢字・カタカナをひらがなに変える設定もあります。

感情・会話状態のアバター連携にも、対応するアバター側の設定が必要です。

**表示されない場合：[困ったとき](../troubleshooting.md)**
