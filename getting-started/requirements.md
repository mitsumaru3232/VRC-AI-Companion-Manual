# 動作環境と必要なもの

## 用意するもの

| 項目 | 必要なもの |
| --- | --- |
| パソコン | Windows 11 64bit（x64）、Intel / AMDのx64対応CPU |
| 会話用AI | Ollamaとローカルモデル、または対応するクラウドAIのAPIキー |
| マイク | 音声で話しかける場合に必要。文字入力だけなら不要 |
| インターネット | 初回のモデル取得に必要。クラウドAIでは会話中も必要 |
| VRChat | VRChat内への表示を使う場合。VACと同じWindows PCで起動する構成を案内します |

Windows 10は動作未確認です。macOS、Linux、Windows ARM版は対象外です。
すべてのPC・オーディオ機器で動作を保証するものではありません。

## 空き容量

本体はZIPを展開すると約0.8GBです。これに加えて、選んだモデルの保存領域が必要です。

WhisperでNVIDIA GPUを使う場合は、初回に約1.36GBの追加部品を取得します。
取得・展開のために追加で約3.5GB、取得後の保存に約2.1GBを使います。
CPUで使う場合、NVIDIA GPUがない場合、Parakeetだけを使う場合は、このGPU部品は不要です。

モデルの必要容量は種類によって異なります。取得前に空き容量を確認してください。

## メモリと処理速度

ローカル会話AIとVRChatは、どちらもパソコンのメモリやGPUを使います。
モデルが大きいほど速い・快適とは限りません。「AI を選ぶ」にある容量とメモリの目安を確認してください。

音声認識はCPUでも使えます。WhisperのGPU処理は対応するNVIDIA GPU向けで、AMD / Intel GPUによる高速化には対応していません。
ParakeetはCPUで動作します。Ollama側のGPU対応とは別の条件です。
