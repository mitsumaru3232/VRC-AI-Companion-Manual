# ダウンロードと初回起動

## 1. ZIPを展開する

1. BOOTHの購入履歴から、その版の配布ZIPをダウンロードします。
2. ZIPを右クリックし、「すべて展開」を選びます。
3. 展開した「VRC AI Companion」フォルダを、書き込みできる場所に置きます。

**すでに展開済みで「★はじめに.txt」を読んでいる方は、次の手順へ進んでください。**

## 2. EXEを起動する

フォルダ内の **VRC AI Companion.exe** をダブルクリックします。
隣の **_internal** は動作に必要な部品です。移動する場合はフォルダごと移動してください。

ZIPの中から直接起動せず、展開したフォルダから起動します。
初回はセットアップ画面が開きます。すでに起動している場合は、既存の画面が表示されることがあります。

Windowsが起動を止めた場合は、購入先・ファイル名・発行元などの表示を確認してください。
心当たりのないファイルや警告内容が分からない場合は、[お問い合わせ](../support.md)に進んでください。
セキュリティ機能を一括で無効にする必要はありません。

## 3. AIを準備する

クラウドAIを使う場合は、ご自身で発行したAPIキーを用意します。
Ollamaを使う場合は、Ollama本体と会話モデルの導入が必要です。

**次へ：[使うAIを選ぶ](../ai/README.md) → [初回セットアップ](setup.md)**
